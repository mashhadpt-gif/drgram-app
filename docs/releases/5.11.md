# DrGram 5.11

- Version name: 5.11
- Version code: 52
- Build target: `:TMessagesProj_App:assembleAfatRelease`
- ABI set: `armeabi-v7a, arm64-v8a, x86, x86_64`

## Included camera and story improvements

This release line includes the camera and story work merged since 5.3, including camera looks and beauty controls, persisted presets, nose shaping and teeth whitening, face landmark-based placement with fallback behavior, temporal smoothing for live face anchors, and eye enlargement/lower-face shaping in preview and saved-photo processing.

The existing Telegram story editor features remain part of the app; this note does not claim new implementations for GIF/sticker/drawing/video-trimming features beyond what is present in the repository.

## Build and validation

The GitHub Actions workflow `.github/workflows/android-build.yml` compiles the universal `afatRelease` APK and uploads it as the `DrGram-5.11-universal-APK` artifact.

A successful compile verifies source/build integration, but it does not replace camera testing on physical devices. Before distributing, validate front/rear cameras, rotation, face movement, recording, and saved-photo retouching across multiple devices.
